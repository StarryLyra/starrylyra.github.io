Book Tracker Database

PostgreSQL SQL Database Design

Goodreads houdt bij wat je hebt gelezen, maar biedt weinig inzicht in onafgemaakte series. Voor mijn CS50 SQL-eindproject bouwde ik daarom een PostgreSQL-database met 200+ boeken uit mijn eigen bibliotheek. Goodreads tracks what you have read, but provides limited insight into unfinished series. For my CS50 SQL final project, I built a PostgreSQL database using 200+ books from my own library.

RNA-seq QC Checker

Python Pandas Data Analysis

Kwaliteitscontrole van RNA-seq data gebeurt vaak handmatig en inconsistent. Ik bouwde daarom een Python-tool die counts-matrices automatisch controleert op kwaliteitsproblemen, met een overzichtelijk HTML-rapport als output. RNA-seq data quality control is often manual and inconsistent. I built a Python tool that automatically checks counts matrices for quality issues, producing a clear HTML report as output.

Wat ik heb gebouwd

What I built

  • Library size-controle: detecteert samples met afwijkend lage sequencing-diepte
  • Detection rate-check: signaleert samples met een ongewoon laag aantal gedetecteerde genen
  • PCA-outlierdetectie: identificeert samples die statistisch afwijken van de rest van de dataset
  • Praktijkvraag: "Hoeveel van de test-samples werden als outlier gemarkeerd?" → 1 van de 5
    •
  • Library size-controle: flags samples with unusually low sequencing depth
  • Detection rate-check: flags samples with an unusually low number of detected genes
  • PCA-outlierdetectie: identifies samples that statistically deviate from the rest of the dataset
  • Practical question: "How many test samples were flagged as outliers?" → 1 of 5

Cardiovascular Risk Dashboard

Power BI Power Query Healthcare Analytics

Cardiovasculair risico is complex, maar wordt vaak samengevat in één simpel getal. Voor dit project bouwde ik een Power BI-dashboard dat cardiovasculair risico inzichtelijk maakt op basis van 70.000 records uit een publieke Kaggle-dataset. Cardiovascular risk is complex, but is often summarized into a single simple number. For this project, I built a Power BI dashboard that makes cardiovascular risk visible based on 70,000 records from a public Kaggle dataset.

Wat ik heb gebouwd

What I built

  • Gewogen risicoscore: berekend op basis van klinische risicofactoren, onderbouwd door ACC/AHA-richtlijnen
  • Vijf dashboardpagina's: van populatie-overzicht tot individuele risicoprofielen
  • Power Query en interactieve filters: data-transformatie met Power Query, met filters voor exploratie per leeftijdsgroep, geslacht of risicofactor
  • Praktijkvraag: "Welke risicofactor maakt het grootste verschil?" → cholesterol (76% vs 44%)
    •
  • Weighted risk score: calculated from clinical risk factors, grounded in ACC/AHA guidelines
  • Five dashboard pages: from population overview to individual risk profiles
  • Power Query and interactive filters: data transformation using Power Query, with filters for exploring by age group, gender, or risk factor
  • Practical question: "Which risk factor makes the biggest difference?" → cholesterol (76% vs 44%)
